Kontrol manual, untuk saat mode otomatis merusak videomu

Eksposur otomatis naik turun saat ada orang lewat di depan jendela. White balance otomatis bergeser di tengah take, dan warna videomu berubah antar potongan. Panel manual ContentCam dibuat persis untuk momen seperti itu.

Kontrol apa saja yang bisa diatur manual?

KontrolRentangKapan dipakai
Eksposur (EV bias)Diputar di sekitar nilai otomatisAdegan terlihat terlalu terang atau terlalu gelap, tapi kamu tetap ingin mode otomatis yang bekerja.
White balance2500K – 8000KKunci suhu warna supaya cahaya campuran (jendela + lampu) tidak bergeser antar take. 2700K untuk lampu indoor yang hangat, ~5500K untuk siang hari, lebih tinggi untuk tempat teduh.
ISORoda manual, sesuai rentang hardwareKunci sensitivitas untuk mengendalikan noise, daripada membiarkan mode otomatis menaikkannya saat cahaya minim.
Shutter speedRoda manual, sesuai rentang hardwareIkuti aturan 180° (1/60 di 30fps) untuk motion blur yang natural, atau lebih cepat untuk membekukan gerakan.

Ditambah yang dasar: tap untuk fokus, geser untuk eksposur, cubit untuk zoom, pindah lensa 0,5×/1×/2×, dan lampu kilat. Semua pengaturan manual berlaku untuk kedua file hasil rekaman, vertikal dan horizontal.

Detail yang terasa saat dipakai

Coba dulu sebelum beli

Semua dial langsung bisa dipakai di versi gratis. Kamu bisa lihat sendiri efek white balance manual pada adeganmu sebelum membayar. Tawaran Premium baru muncul saat kamu merekam dengan kontrol manual aktif.

Pengaturan tetap tersimpan

Pengaturan manualmu bisa tetap bertahan saat pindah lensa dan saat aplikasi dibuka ulang (ada tombolnya di Pengaturan). Atur tampilanmu sekali, pakai terus sepanjang syuting.

Ada juga di Android

White balance manual (suhu warna dan tint), ISO, dan shutter tersedia di ContentCam untuk Android, selama hardware kamera ponselnya mendukung.

Jujur soal hardware

Kalau sebuah lensa atau perangkat tidak bisa melakukan sesuatu (misalnya kontrol sensor manual di sebagian kamera depan), aplikasi akan bilang terus terang, bukan pura-pura bisa.

Pertanyaan

Apakah pengaturan manual berlaku untuk kedua file hasil rekaman?

Ya. Eksposur, white balance, ISO, dan shutter diterapkan langsung saat perekaman, jadi file vertikal dan horizontal hasilnya sama persis.

Apakah kontrol manual bisa dipakai bareng teleprompter?

Bisa, keduanya terpisah. Kunci eksposurmu, buka naskahmu, lalu rekam.

Apa itu aturan shutter 180 derajat?

Atur shutter speed kira-kira dua kali frame rate (1/60 di 30fps) untuk motion blur yang biasa kita lihat di film. Penjelasan lengkapnya di sini.
