Androidでインカメラと外カメラを同時に録画する方法

文：Jimmy（ContentCam開発者）· 2026年10月8日

一部のSamsung Galaxyは、標準の「カメラ」アプリでインカメラと外カメラを同時に録画できます。Pixelカメラではできません。2つのカメラを同時に動かせるハードウェアを持つAndroidスマホなら、前後カメラのモードがあるカメラアプリで同時録画ができます。ContentCamの前後カメラ（Front/Back）モードは、あなたの顔と目の前の光景を別々の2つのファイルとして保存します。

以下では、それぞれの方法で何ができるのか、どの機種で使えるのか、そしてリアクションがきちんと伝わる撮り方を紹介します。Instagramに内蔵された機能を含め、iPhoneとAndroidでの方法をすべて知りたい場合は、インカメラと外カメラを同時に使う方法のメインガイドをご覧ください。iPhoneでも撮影するなら、新しい機種の標準「カメラ」アプリには独自の機能、iPhoneのDual Captureがあります。こちらは2つのカメラの映像を、ワイプ（ピクチャ・イン・ピクチャ）の1つのファイルとして保存します。

Galaxyでインカメラと外カメラを同時に録画するには？（ディレクターズビューとデュアル録画）

Samsungは、この機能を「カメラ」アプリに組み込んでいます。サポートページでは、ディレクターズビュー（Director's View）のデュアル録画（Dual recording）を「背面カメラとセルフィーカメラで同時に動画を録画する」方法として紹介しており、One UI 3.1以降の一部の機種で使えます。録画の前にレイアウトを選びます。

  • ピクチャ・イン・ピクチャ：背面カメラの映像の隅に、あなたが小さなワイプで入ります。
  • 分割：上が背面カメラ、下がセルフィーカメラです。
  • シングル：カメラは1つだけで、ディレクターズビューを使ってレンズを切り替えます。

注意点が2つあります。1つ目は、仕上がりが通常は1本の動画で、選んだレイアウトに顔が焼き込まれることです。編集でワイプを動かしたり消したりはできません。Samsungのページによると、Galaxy S22とS23では、録画前にオンにしておけば、セルフィーと背面カメラの動画を別々のファイルとして保存できます。2つ目は、Galaxy S24、S25以降ではディレクターズビューの名前がデュアル録画に変わり、One UI 8.5では動画モードのクイックコントロールの中に移ったことです。詳しい手順と対応機種は、Galaxyで前後カメラを同時に録画する方法にまとめています。

Pixelでインカメラと外カメラを同時に録画できる？

Pixelカメラでは、2つのカメラを同時に録画できません。Googleのヘルプページでいちばん近いのは、Pixel Foldシリーズのデュアルスクリーンプレビュー（Dual screen preview）です。内側と外側の画面にプレビューを映して、撮られている人が自分の姿を確認できるようにする機能ですが、録画しているのはやはり1つのカメラです。Pixelで前後カメラを同時に録画するには、サードパーティ製のアプリが必要です。

ほかのAndroidスマホで同時録画できるかはどう決まる？

Android 11（APIレベル30）で追加されたgetConcurrentCameraIds()は、スマホのどのカメラを同時に動かせるかをアプリに伝えます。スマホがインカメラと背面カメラの組み合わせを報告していれば、アプリは両方を録画できます。報告していなければ、その公式の方法を使う限り、どんなに優れたアプリでも録画できません。見た目は同じくらい高性能なスマホなのに、前後カメラの同時録画が片方ではでき、もう片方ではできないのはこのためです。

ContentCamを使ってAndroidで前後カメラを同時に録画するには？

ContentCamの前後カメラ（Front/Back）モードは、1回タップするだけでインカメラと背面カメラを同時に録画し、レイアウトが焼き込まれた1本の動画ではなく、2つのファイルとして保存します。背面カメラは縦か横かを選んで録画でき、インカメラは常に縦です。2つが別々なので、レイアウトはあとから決められます。ワイプ、画面分割、2つの映像の切り替え、あるいは1回のテイクから2本の別々の投稿をつくることもできます。

  1. Google PlayからContentCamをインストールして開きます。
  2. 録画モードを前後カメラ（Front/Back）に切り替えます。
  3. 背面カメラを縦で録画するか横で録画するかを選びます。
  4. 背面カメラの構図を決めて、1回録画します。2つのカメラは同じタイムラインで録画されるので、リアクションと目の前の光景はずれません。
  5. 2つのクリップを並べて確認し、トリミングして書き出します。

前後カメラ（Front/Back）はPremiumの機能で、まずは5回まで無料で試せます。Android版のほかの機能と同じく、スマホのカメラが報告する実際の対応状況に合わせて動作します。無料版でも、縦と横を同時に撮る録画はできます。1回のテイクから9:16の縦と16:9の横のファイルを録画する機能で、これは別のテーマとしてAndroidで縦と横の動画を同時に録画する方法で解説しています。

どの方法を選べばいい？

  • 対応するGalaxyを持っていて、完成した動画をすぐに作りたい：標準の「カメラ」アプリのデュアル録画を使いましょう。ピクチャ・イン・ピクチャか分割を選び、そのまま投稿できます。
  • 2つのアングルを別々に編集したい、またはPixelやほかのメーカーのスマホを使っている：2つのファイルを保存するアプリを使いましょう。
  • ストーリーズ1本のために、隅に顔を入れたいだけ：Instagramのデュアルカメラ機能で足りるかもしれません。デュアルカメラのメインガイドで紹介しています。

前後カメラの動画を上手に撮るコツは？

  • 顔に光を当てる。インカメラは性能が低いほうで、暗い部屋では背面カメラよりずっと早くノイズが出ます。窓かライトのほうを向きましょう。
  • 声はマイクの近くで。スマホのマイクは、いちばん近くにいる人の声を拾います。何かを見せようと後ろに下がると声が小さくなるので、大事なセリフのときは近づきましょう。
  • 明るさの違う場所を移動するなら露出を固定する。明るい窓際から暗い部屋に歩いていくと、2つのカメラとも露出が定まらず、明るさがふらつきます。スマホで何を固定できるかは、Androidのカメラ設定ガイドで解説しています。
  • 発熱に気をつける。2つのカメラを同時に動かすのは、スマホにとって重い処理です。長回しのときは直射日光を避け、ケースを外しましょう。

よくある質問

Pixelでインカメラと外カメラを同時に録画できますか？

Pixelカメラではできません。Pixel Foldシリーズのデュアルスクリーンプレビュー（Dual screen preview）は2つの画面を使う機能で、2つのカメラを使う機能ではありません。2つのカメラの同時使用に対応したPixelで、前後カメラのモードがあるアプリを使ってください。

Galaxyのデュアル録画は2つのファイルに分けて保存できますか？

通常は、レイアウトが焼き込まれた1本の動画として保存されます。Samsungによると、Galaxy S22とS23では、録画前に設定しておけば、インカメラと背面カメラのファイルを別々に保存できます。

ContentCamの前後カメラ（Front/Back）モードはAndroidで無料で使えますか？

アプリ本体と、縦と横を同時に撮る録画は無料です。前後カメラ（Front/Back）はPremiumの機能で、5回まで無料で試せます。

自分のスマホでインカメラと外カメラを同時に録画できないのはなぜですか？

スマホのハードウェアが、インカメラと背面カメラの同時動作に対応している必要があります。Android 11以降では、スマホがその対応状況をgetConcurrentCameraIds()を通じてアプリに伝えます。対応していなければ、公式の方法で両方のカメラを録画できるアプリはありません。

ContentCamを無料で試す。前後カメラを1回のテイクで別々の2つのファイルに、さらに1回の撮影で縦と横の両方も。AndroidとiPhoneで無料でダウンロードできます。
