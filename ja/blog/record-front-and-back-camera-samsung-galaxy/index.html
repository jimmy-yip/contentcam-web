Galaxyでインカメラと外カメラを同時に録画する方法

文：Jimmy（ContentCam開発者）· 2026年10月10日 · 2026年11月5日更新

Samsung Galaxyでインカメラと外カメラを同時に録画するには、Samsungの「カメラ」アプリのデュアル録画（Dual recording）を使います。One UI 8.5では動画モードのクイックコントロールの中に、それより前のソフトウェアでは「その他」の中にあります。デュアル録画は、ディレクターズビュー（Director's View）の新しい名前です。自分の顔と目の前の光景を別々の2つのファイルで残したい場合、Samsungの「カメラ」アプリでそれができるのはGalaxy S22とS23だけです。それ以外のGalaxyでも、2つのカメラを同時に動かせる機種なら、ContentCamの前後カメラ（Front/Back）モードで、セルフィーと背面カメラの映像を1回のテイクで別々の2つのファイルとして録画できます。

お断り：私はContentCamをつくっているので、中立ではありません。Samsungに関する情報はSamsungのサポートページから、ほかのアプリの詳細はGoogle Playの掲載情報とレビューから引用しており、2026年11月5日に確認しました。PixelやそのほかのAndroidスマホについては、Androidで前後カメラを同時に録画する方法をご覧ください。

Galaxy S24・S25でディレクターズビューが見つからないのはなぜ？

Samsungがディレクターズビューの名前をデュアル録画に変えたからです。Samsung米国のサポートには「ディレクターズビューはGalaxy S24シリーズおよびS25シリーズでは利用できません」とあり、Samsung Gulfの「Director's View Missing in Camera?」（2026年7月1日更新）はこう説明しています。「新しいSamsung Galaxyでは、ディレクターズビューのメニューの名前がデュアル録画に変更されました」。

デュアル録画に対応しているGalaxyの機種は？

Samsungは、デュアル録画の対応機種として次の5つのグループを挙げています。

  • Galaxy S24シリーズ
  • Galaxy S25シリーズ
  • Galaxy Z Foldシリーズ
  • Galaxy Z Flipシリーズ
  • Galaxy Aシリーズ（一部の機種。Samsungは機種名を公表していません）

Samsungによると、新しい機種ではFHDまたはUHDの30fps、「Front + Rear」（インカメラ＋背面カメラ）、「Rear + Rear」（背面カメラ＋背面カメラ）が選べます。Galaxy S23シリーズはFHD 30fpsと「Front + Rear」に限られていました。

One UI 8.5でデュアル録画をオンにするには？

Samsung米国のサポートページによると、One UI 8.5からデュアル録画（Dual rec）は「動画メニューに統合されました」。

  1. 「カメラ」アプリを開き、「動画」をタップします。
  2. クイックコントロールのアイコン（4つの円）をタップします。
  3. 「デュアル録画」（四角の隅に小さな四角があるアイコン）をタップして録画します。

デュアル録画を独立したモードに戻すには、Camera Assistantの追加モードでオンにします（Samsung Indiaでは「Downloadable」と表記されています）。オンにすると「その他」の中に表示されます。One UI 8.5より前は、「カメラ」、「その他」、「デュアル録画」の順です（古い機種では「ディレクターズビュー」）。

Samsungのデュアル録画は別々のファイルで保存できる？

できるのはGalaxy S22とS23シリーズだけです。Samsungのサポートページによると、S22とS23では録画前にダウンロードアイコンをタップすると、2つの動画を別々に保存できます。また「この設定は現在、S22シリーズとS23シリーズ以外の機種では利用できません」とも書かれています。それ以外の機種では、デュアル録画は録画前に選んだワイプ（ピクチャ・イン・ピクチャ）か画面分割が焼き込まれた、1本の動画として保存されます。

Galaxyがほかのアプリで2つのカメラを同時に使えるか確認するには？

Android 11で、機能フラグandroid.hardware.camera.concurrentが追加されました。Android Developersでは、このフラグを「デバイスのメインのインカメラと背面カメラが同時にストリーミングできる」ことと定義しています。GoogleのAndroid Developers BlogのCameraX 1.3に関する記事では、2つのカメラを使う場合の上限はスマホによって「720pまたは1440p」とされています。

いちばん簡単な確認方法は、スマホをチェックしてくれるアプリを使うことです。ContentCamは2つのカメラを同時に動かせる場合にだけ前後カメラ（Front/Back）を表示するので、このモードは使えるか、表示されないかのどちらかです。チェックが大切な理由はレビューを見るとわかります。Dual Cam: Front and Back Video（VysionApps）のGoogle Playの最新レビュー39件のうち2件が、2つのカメラで録画できなかったと書いています。たとえば「2つのカメラを有効にして同時に録画することができません。」（星1つ、2026年9月26日）というレビューです。パソコンがあれば、adb shell pm list featuresを実行し、android.hardware.camera.concurrentが表示されれば対応しています。

ContentCamでGalaxyの前後カメラを同時に録画するには？

  1. Google PlayからContentCamをインストールします。
  2. 録画モードを前後カメラ（Front/Back）に切り替えます。このモードが表示されない場合、そのGalaxyはアプリで2つのカメラを同時に動かせません。
  3. 背面カメラの縦か横を選び、1回録画します。セルフィーと背面カメラの映像が同期して録画され、別々の2つのファイルとして保存されます。

ファイルが2つあるので、顔と光景を切り替えて編集したり、別々に投稿したり、ContentCamの「合成」エディタでワイプ（ピクチャ・イン・ピクチャ）や画面分割の1本の動画にしたりできます（保存はPremiumの機能です）。照明や音声のコツはリアクション動画の撮り方ガイドにまとめています。

よくある質問

Galaxy S24やS25ではディレクターズビューはなくなったのですか？

なくなったのは名前だけです。Samsungはディレクターズビューの名前をデュアル録画に変えました。デュアル録画の対応機種として、SamsungはGalaxy S24、S25、Z Fold、Z Flip、一部のGalaxy Aを挙げています。

One UI 8.5でデュアル録画はどこにありますか？

One UI 8.5から、Samsungはデュアル録画を動画モードの中に移しました。「カメラ」を開いて「動画」をタップし、クイックコントロール（4つの円）をタップしてから、「デュアル録画」をタップします。

Galaxyでインカメラと外カメラを別々の2つのファイルで保存できますか？

Samsungによると、Samsungの「カメラ」アプリでできるのはGalaxy S22とS23シリーズだけです。ほかのGalaxyでは、デュアル録画は1本の動画として保存されます。2つのカメラを同時に動かせるGalaxyなら、どの機種でも、ContentCamの前後カメラ（Front/Back）モードでセルフィーと背面カメラの映像を別々の2つのファイルとして保存できます。

自分のGalaxyがインカメラと外カメラを同時に使えるか確認するには？

スマホが、Android 11で追加されたAndroidの同時カメラ機能android.hardware.camera.concurrentに対応していると報告する必要があります。ContentCamはスマホを自動でチェックし、動作する場合にだけ前後カメラ（Front/Back）を表示します。

ContentCamを無料で試す。前後カメラを1回のテイクで別々の2つのファイルに、さらに1回の撮影で縦と横の両方も。AndroidとiPhoneで無料でダウンロードできます。
