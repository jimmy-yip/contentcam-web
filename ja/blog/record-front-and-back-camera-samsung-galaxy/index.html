Galaxyでインカメラと外カメラを同時に録画する方法

文：Jimmy（ContentCam開発者）· 2026年10月10日 · 2026年11月5日更新

Samsung Galaxyでインカメラと外カメラを同時に録画するには、Samsungの「カメラ」アプリのデュアル録画（Dual recording）を使います。One UI 8.5では動画モードのクイックコントロールの中に、それより前のソフトウェアでは「その他」の中にあります。デュアル録画は、ディレクターズビュー（Director's View）の新しい名前です。自分の顔と目の前の光景を別々の2つのファイルで残したい場合、Samsungの「カメラ」アプリでそれができるのはGalaxy S22とS23だけです。ほかのGalaxyでは、ContentCamの前後カメラ（Front/Back）モードのようなアプリを使いましょう。

お断り：私はContentCamをつくっているので、中立ではありません。以下のSamsungに関する情報はすべてSamsung自身のサポートページから、ほかのアプリの詳細はすべてGoogle Playの掲載情報から引用しており、2026年11月5日に確認しました。Pixelを含むAndroidスマホ全般については、Androidで前後カメラを同時に録画する方法をご覧ください。

Galaxy S24・S25でディレクターズビューが見つからないのはなぜ？

Samsungがディレクターズビューの名前をデュアル録画に変えたからです。Samsungのサポートページ「Use Director's View and Dual recording on your Galaxy phone」によると、ディレクターズビューはOne UI 3.1以降を搭載した一部の機種に導入された機能で、「ディレクターズビューはGalaxy S24シリーズおよびS25シリーズでは利用できません」と書かれています。Samsungの別のページ「Director's View Missing in Camera?」（2026年7月1日更新）がその理由を説明しています。「新しいSamsung Galaxyでは、ディレクターズビューのメニューの名前がデュアル録画に変更されました」。

デュアル録画に対応しているGalaxyの機種は？

Samsungは、デュアル録画の対応機種として次の5つのグループを挙げています。

  • Galaxy S24シリーズ
  • Galaxy S25シリーズ
  • Galaxy Z Foldシリーズ
  • Galaxy Z Flipシリーズ
  • Galaxy Aシリーズ（一部の機種。Samsungは機種名を公表していません）

新しい機種ほど選べる設定が増えます。SamsungはFHDまたはUHDの30fps、「Front + Rear Camera」（インカメラ＋背面カメラ）、「Rear + Rear Camera」（背面カメラ＋背面カメラ）を挙げており、Galaxy S23シリーズはFHDの30fpsと「Front + Rear Camera」に限られていたと記しています。

One UI 8.5でデュアル録画をオンにするには？

Samsung米国のサポートページによると、One UI 8.5からデュアル録画（Dual rec）は「動画メニューに統合されました」。

  1. 「カメラ」アプリを開き、「動画」をタップします。
  2. クイックコントロールのアイコン（4つの円）をタップします。
  3. 「デュアル録画」（四角の隅に小さな四角があるアイコン）をタップして録画します。

デュアル録画を独立したモードに戻すには、クイックコントロール、歯車アイコン、Camera Assistantの順にタップし、追加モードのデュアル録画をオンにします。Samsung Indiaのページでは「Camera Assistant (Downloadable)」と表記されているため、最初にダウンロードが必要な場合があります。オンにすると、デュアル録画は「その他」の中に表示されます。One UI 8.5より前のソフトウェアでは、Samsungの手順は「カメラ」、「その他」、「デュアル録画」の順です（古い機種では「ディレクターズビュー」）。

Samsungのデュアル録画は別々のファイルで保存できる？

できるのはGalaxy S22とS23シリーズだけです。Samsungのサポートページによると、S22とS23では録画前にダウンロードアイコンをタップすると、セルフィーの動画と背面カメラの動画を別々のファイルとして保存できます。また「この設定は現在、S22シリーズとS23シリーズ以外の機種では利用できません」とも書かれています。それ以外の機種では、デュアル録画は録画前に選んだワイプ（ピクチャ・イン・ピクチャ）か画面分割が焼き込まれた、1本の動画として保存されます。

Galaxyがほかのアプリで2つのカメラを同時に使えるか確認するには？

Android 11（APIレベル30）で、同時に動かせるカメラの組み合わせを返すCameraManager.getConcurrentCameraIds()と、機能フラグandroid.hardware.camera.concurrentが追加されました。Android Developersのドキュメントでは、このフラグを「デバイスのメインのインカメラと背面カメラが同時にストリーミングできる」ことと定義しています。インカメラと背面カメラの組み合わせがなければ、この公式の方法で両方を録画できるサードパーティ製アプリはありません。GoogleのCameraXのドキュメントでは、2つのカメラを使う場合の上限はスマホによって「720pまたは1440p」とされています。

いちばん簡単な確認方法は、スマホをチェックしてくれるアプリを使うことです。ContentCamは動作する場合にだけ前後カメラ（Front/Back）を表示し、DuoCamの掲載情報には「起動時にスマホのハードウェアをチェックする」とあります。パソコンがあれば、adb shell pm list featuresを実行し、android.hardware.camera.concurrentが表示されれば対応しています。

ContentCamでGalaxyの前後カメラを同時に録画するには？

  1. Google PlayからContentCamをインストールします。
  2. 録画モードを前後カメラ（Front/Back）に切り替えます。このモードが表示されない場合、そのGalaxyはアプリで2つのカメラを同時に動かせません。
  3. 背面カメラの縦か横を選び、1回録画します。セルフィーと背面カメラの映像が同期して録画され、別々の2つのファイルとして保存されます。

ファイルが2つあるので、顔と光景を切り替えて編集したり、別々に投稿したり、ContentCamの「合成」エディタでワイプ（ピクチャ・イン・ピクチャ）や画面分割の1本の動画にしたりできます（保存はPremiumの機能です）。照明や音声のコツはリアクション動画の撮り方ガイドにまとめています。

よくある質問

Galaxy S24やS25ではディレクターズビューはなくなったのですか？

なくなったのは名前だけです。Samsungはディレクターズビューの名前をデュアル録画に変えており、デュアル録画の対応機種として、Galaxy S24シリーズ、Galaxy S25シリーズ、Galaxy Z Foldシリーズ、Galaxy Z Flipシリーズ、一部のGalaxy Aシリーズを挙げています。

One UI 8.5でデュアル録画はどこにありますか？

One UI 8.5から、Samsungはデュアル録画を動画モードの中に移しました。「カメラ」を開いて「動画」をタップし、クイックコントロール（4つの円）をタップしてから、「デュアル録画」をタップします。

Galaxyでインカメラと外カメラを別々の2つのファイルで保存できますか？

Samsungによると、Samsungの「カメラ」アプリでできるのはGalaxy S22とS23シリーズだけです。ほかのGalaxyでは、デュアル録画は1本の動画として保存されます。ContentCamの前後カメラ（Front/Back）モードやDuoCamなどのアプリなら、2つのカメラを同時に動かせるGalaxyで、別々のファイルとして保存できます。

自分のGalaxyがインカメラと外カメラを同時に使えるか確認するには？

スマホが、Android 11で追加されたAndroidの同時カメラ機能android.hardware.camera.concurrentに対応していると報告する必要があります。ContentCamとDuoCamはスマホを自動でチェックし、動作する場合にだけ前後カメラの録画を表示します。

ContentCamを無料で試す。前後カメラを1回のテイクで別々の2つのファイルに、さらに1回の撮影で縦と横の両方も。AndroidとiPhoneで無料でダウンロードできます。
